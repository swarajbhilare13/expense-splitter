Expense Splitter
A simple command-line Python application that helps roommates or friends split shared expenses fairly.
This project allows users to add people, record expenses, and calculate how much each person owes or should receive after splitting the total amount equally.

Features Implemented
- Add multiple people
- Record expenses with:
  - payer name
  - amount paid
- Calculate total shared expense
- Split expenses equally among all members
- Display balances:
  - who should pay
  - who should receive money
- Menu-driven command-line interface

Technologies Used
- Python
- Lists
- Dictionaries
- Functions
- Loops and Conditional Statements

How It Works
1. Add people participating in shared expenses
2. Enter expenses and who paid them
3. The program calculates:
   - total expense
   - equal share per person
   - final balances
